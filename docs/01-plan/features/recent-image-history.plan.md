# Plan: 최근 이미지 내역 (시드 10개 + 결과 10개)

## 1. 개요

### 1.1 요구사항
- 시드 이미지 최근 10개, 변환 결과 최근 10개를 **각각** 자동 저장
- 오래된 것부터 자동 삭제 (FIFO)
- 배치 변환 탭에서 최근 시드/결과를 원본으로 바로 선택 가능

### 1.2 사용자 플로우
```
시드관리: 얼굴 A 업로드 → 시드 저장 (최근 시드 목록에 자동 추가)
헤어변경: 참조 B + 시드 A → 결과 C (최근 결과 목록에 자동 추가)
배치변환: "최근 시드"에서 A 선택 or "최근 결과"에서 C 선택 → 대량 생성
```

### 1.3 현재 문제점
1. `seed_images`는 session_state에만 저장 → 새로고침 시 소멸
2. `processing_history`는 무한 누적 (limit 없음)
3. 배치 탭에서 시드/결과 선택이 라디오 3개로 분리 → UX 복잡

## 3. 수정 범위

### 3.1 session_state 초기화 (447~451줄)
- `seed_images`: dict → **OrderedDict** 또는 list로 변경하여 순서 보장
  - 현재 dict `{uuid: {image, filename, ...}}` → 순서는 Python 3.7+ dict가 보장하므로 dict 유지 가능
- 최대 10개 제한 상수 추가: `MAX_SEED_IMAGES = 10`, `MAX_PROCESSING_HISTORY = 10`

### 3.2 시드 저장 (1844~1866줄)
- 저장 후 `seed_images` 길이 체크
- 10개 초과 시 가장 오래된 항목 삭제 (첫 번째 키)

### 3.3 헤어 변경 결과 저장 (2021줄)
- `processing_history.append()` 후 길이 체크
- 10개 초과 시 `processing_history.pop(0)` (가장 오래된 것 삭제)

### 3.4 배치 탭 이미지 소스 UI (2103~2144줄)
- 라디오 3개 ("새 이미지 업로드", "저장된 시드에서 선택", "헤어 변경 결과 사용") → 유지
  - 이미 구조적으로 분리되어 있고, "최근 10개" limit만 추가하면 충분
- "저장된 시드에서 선택": 최근순 정렬, 최대 10개 표시
- "헤어 변경 결과 사용": 최근순 정렬, 최대 10개 표시
